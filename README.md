# HaloPixelLyric — 网易云歌词 → 花再 Halo PixelBar 像素屏

轻量级单文件工具：通过 **CDP（Chrome DevTools Protocol）** 从网易云音乐 PC 客户端的网页层
直接读取"正在显示的歌词行"，经 USB HID 推送到漫步者花再 Halo PixelBar 像素屏显示。

**不注入 DLL、不读写进程内存、不依赖网易云版本的内存偏移**

> 本项目是完全 vibe coding 的产物：由 [ZCode](https://zcode.dev)（模型 **GLM-5.3**）与本人
> 通过自然语言协作完成——从方案调研、可行性实测、全部代码到发布打包，均由 AI 编写，
> 本人仅仅负责提出需求、实测体验与方向决策。功劳归于 AI 协作，不归于个人。

## 特性

- **精确跟随演唱**：利用网易云歌词行自带的 `data-time` 时间戳，翻页时机与实际演唱进度对齐，并内置提前量抵消显示链路固有延迟，体感近零延迟
- **长句智能分页**：超过屏幕宽度（实测半角 32 字符 / 全角 16 字）自动分页，优先在空格/标点处断开，两页均衡，不切断词语、不出现孤字尾页
- **演唱时长驱动的分页驻留**：每页显示多久 = 本句实际演唱时长 × 该页字数占比；快节奏歌曲自动加速翻页
- **间奏异常钳制**：自动识别并修正网易云"间奏前一句 + 整段间奏"被计为单句时长的时间戳 bug
- **积压跳句**：歌词过于密集时直接显示最新句，宁可跳句也不滞后演唱
- **断线自愈**：CDP 连接断开自动重连、页面上下文销毁自动重新注入
- 退出时自动把像素屏恢复为时钟模式

## 系统要求

- Windows 10/11 x64（免安装 .NET，单文件自带运行时）
- 漫步者花再 Halo PixelBar（USB 连接电脑）
- 网易云音乐 PC 版（任意较新版本；开发验证于 3.1.36）

## 快速开始

1. 解压任意目录
2. 双击 `start.bat`
   - 脚本会自动定位网易云音乐；若找不到，按提示在脚本里手动填路径
   - 若网易云未带调试参数运行，脚本会自动带 `--remote-debugging-port=9222` 重启它
   - 注意：带参数启动后网易云功能完全不受影响；不想要调试口时正常重启网易云即可
3. **首次使用**：在网易云里打开一次播放页（点击底部播放条的歌曲信息进入黑胶页），歌词组件挂载后，之后切到任何页面都能持续工作
4. 停止：`stop.bat`（像素屏恢复时钟）

可选项：在漫步者官方 App / TempoHub 的"音乐可视化"里设置歌词进入/退出动画（如"从底部往上"），
本工具推送的歌词会自动继承该动画效果。

## 翻页算法与调参

```
新句到来（watcher 检测到 li.current 轮转，即网易云数据层切换 ≈ 演唱到达该句）
  ├─ 句长 = 下一行 data-time − 当前行 data-time（网易云官方编排时间）
  ├─ 间奏钳制：句长 > 按字数估算的合理演唱时长 ×3 → 判定为间奏拉伸，回退估算值
  ├─ 超屏长句 → 分页（均衡切分，空格/标点优先，每页 ≤16 全角 / ≤32 半角）
  ├─ 每页切换时刻 = 本句开始时刻 + 句长 × 该页字数占比 − 提前量(PageLeadMs)
  └─ 翻页下限：每页至少驻留 clamp(句长/页数, 600, 1200) ms
新句到来时未显示完的页直接丢弃（跳句保实时）
```

**提前量 `PageLeadMs`**（`Program.cs` 顶部参数区，默认 **280ms**）：用于抵消"轮询发现 + HID 传输 +
固件进入动画"的链路固有延迟。**不同设备/固件版本的动画时长可能有差异**——如果你感觉歌词翻页时出现偏早
（抢拍），调小该值；偏晚（慢半拍），调大。修改后 `dotnet build -c Release` 重新构建即可。

其他可调参数（屏宽容量、驻留节奏、间奏钳制倍数等）同样集中在 `Program.cs` 顶部注释区。

## 已知问题

- **网易云间奏时间戳 bug**：网易云会把"间奏前一句 + 整段间奏"计为该句的演唱时长，
  导致官方 data-time 严重失真。本工具以"句长超过字数估算 3 倍"为界识别并回退到估算时长；
  副作用是极个别拖腔极长的句子翻页可能略早于演唱
- **像素屏字库缺字**：个别生僻日文汉字/符号无法渲染（设备字库覆盖问题，缺字处显示空白）
- 歌词行超过 55 UTF-8 字节时尾部截断（HID 单包 64 字节上限，分页后单页天然不触发）
- 请勿与官方客户端 / 其他工具的歌词推送同时开启（多程序写同一 HID 设备会互相覆盖）
- 调试端口 9222 仅监听本机

## 命令行参数

| 参数 | 作用 |
|---|---|
| （无） | 常驻运行，Ctrl+C 退出并恢复时钟 |
| `--clock` | 仅把像素屏恢复为时钟模式 |
| `--calibrate` | 屏宽标定：汉字 4~14（默认）/ `--calibrate en` 半角 20~40 |
| `--test-layout` | 显示模式字节探测（协议研究用） |

## 工作原理

```
网易云（带 --remote-debugging-port=9222 启动，界面为 CEF/Chromium 网页）
  → CDP 注入采集脚本：MutationObserver 监听歌词列表 "line current" 的 class 轮转
    （网易云数据层行为，与播放页是否可见无关）
  → 读取当前行文本 + data-time 演唱时间戳
  → C# 宿主低频轮询读取（该定制 CEF 屏蔽了事件推送，请求-响应最可靠）
  → 显示节奏器：分页 / 驻留 / 提前量 / 跳句
  → USB HID 推送到像素屏（静态居中布局，翻页带官方动画）
```

若网易云前端大改版，可能需要调整 `WatcherScript.cs` 中的选择器（`ul.lyric` / `li.current`）。
